## Android release signing

Set `VILLAGESTOWN_KEYSTORE` to the private keystore path and provide
`VILLAGESTOWN_STORE_PASSWORD`, `VILLAGESTOWN_KEY_ALIAS`, and
`VILLAGESTOWN_KEY_PASSWORD` in the build environment.
